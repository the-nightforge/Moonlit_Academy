- Complete accessible names, no repeated tooltips or abbreviated terms.
- Existing five encounter types and rules only. No copied Riot artwork.
- Work on `codex/run-ui`; no merge requested for this revision.

## Review Focus

- Narrow viewport: pan route without horizontal page overflow; reach selected node.

- Actual path: distinguish visited/current/reachable/future/blocked without claiming unplayed nodes.
